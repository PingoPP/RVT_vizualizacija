# RVT_vizualizacija

Pri učenju sem se odločil, da končno začnem uporabljati tudi Python različico orodja Relief Visualization Toolbox (RVT, različica 2.21.2), ki so ga zasnovali na ZRC SAZU. Orodje je odprtokodno in je na voljo tudi kot orodje za QGIS in kot orodje za ArcGIS Pro.


## Namen projekta

Namen projekta je preučiti parametre različnih metod vizualizacije reliefa ter preveriti njihovo uporabnost pri arheoloških raziskavah. Cilj je bolje razumeti vpliv posameznih parametrov na prepoznavnost arheoloških struktur in razviti pristop, ki bo omogočal učinkovitejši pregled ter interpretacijo reliefnih značilnosti.

V projektu bodo predstavljene naslednje kompleksnejše različice vizualizacij:

- **VAT Poskus** – lastna različica z izbranimi parametri
- **VAT Flat**
- **VAT General**
- **VAT Combined**
- **e4MSTP**
- **Prismatic Openness**

**Vizualizacije, ki še niso izdelane (bodo v bodoče narejeni):**
- RGB VAT Combined
- Simple Red Relief
- Modified Red Relief Image Map
- PCA of Hillshading
- Histogram streching
